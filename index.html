Seu objetivo é PROJETAR, DESENVOLVER, TESTAR E ENTREGAR um sistema web completo chamado Escola do Bom Condutor, destinado à gestão do processo de reavaliação teórica e prática de colaboradores envolvidos em acidentes de trânsito. CONTEXTO DO PROGRAMA A Escola do Bom Condutor é um programa corporativo voltado aos colaboradores que estiveram envolvidos em acidentes de trânsito durante suas atividades profissionais. O programa deve permitir que cada colaborador passe por duas etapas obrigatórias: Prova teórica: avaliação de conhecimentos de trânsito e direção defensiva, com questões específicas conforme o tipo de veículo utilizado pelo colaborador. Prova prática: avaliação conduzida por um instrutor de trânsito, com critérios objetivos, registro da avaliação e resultado final. O sistema deve centralizar o processo, permitindo que a empresa acompanhe os colaboradores convocados, as avaliações realizadas, os resultados, as pendências e o histórico de cada participante. A aplicação deverá ser disponibilizada por um link público de acesso para os colaboradores e por uma área administrativa protegida para os responsáveis pelo programa. 2. OBJETIVO PRINCIPAL Criar uma plataforma corporativa moderna, minimalista, futurista e intuitiva que permita: Identificar automaticamente os colaboradores a partir de uma base importada de Excel. Coletar os dados de identificação sem exigir digitação manual de todas as informações. Direcionar o colaborador para a avaliação teórica correspondente ao seu tipo de veículo. Realizar a prova teórica com alternativas de A a E, quando o banco de questões estiver completo. Corrigir automaticamente a prova teórica. Registrar a avaliação prática realizada pelo instrutor. Consolidar os resultados das duas etapas. Gerar indicadores, relatórios e histórico de avaliações. Administrar colaboradores, questões, instrutores, critérios e configurações. Permitir que a aplicação seja utilizada por link, tanto em computadores quanto em celulares. 3. IDENTIFICAÇÃO INTELIGENTE DO COLABORADOR Esta é uma das funcionalidades mais importantes do sistema. A identificação deverá utilizar uma base corporativa de colaboradores importada por planilha Excel. Crie os seguintes campos: Nome completo do colaborador. Matrícula, quando disponível. Base. Função. Gerência. Tipo de veículo. Os campos de identificação deverão ser preenchidos automaticamente conforme o colaborador digitar o nome. Funcionamento do preenchimento automático O colaborador acessa a página de identificação. Digita parte do seu nome no campo "Nome do colaborador". O sistema consulta a base de colaboradores importada. Apresenta uma lista de sugestões correspondentes ao texto digitado. A lista mostra o nome completo e, quando necessário, informações adicionais que ajudem a diferenciar homônimos. O colaborador seleciona seu registro. O sistema preenche automaticamente matrícula, base, função, gerência e tipo de veículo. O colaborador confere as informações. Após confirmar os dados, pode prosseguir para a prova. Exemplo: Ao digitar "FRANCISCO", o sistema pode apresentar: Francisco Antônio da Silva — Base Bacabal. Francisco José Pereira — Base Santa Inês. Francisco Carlos Souza — Base Pedreiras. Os nomes acima são apenas exemplos ilustrativos. Regras do preenchimento Implementar busca incremental com debounce. Aceitar buscas parciais. Tratar diferenças entre letras maiúsculas e minúsculas. Tratar acentos e espaços excedentes. Evitar carregar toda a base de colaboradores no navegador. Exibir somente os dados necessários para a identificação. Não preencher os campos usando valores inventados. Não permitir que o colaborador altere livremente base, função, gerência ou tipo de veículo, pois esses dados devem vir do cadastro oficial. Permitir que o colaborador solicite correção de dados desatualizados. Se houver nomes duplicados, solicitar a seleção correta. Se não houver correspondência, mostrar uma mensagem orientando a procurar o responsável pelo programa. Não permitir o início da prova sem um registro válido de colaborador. Registrar qual versão da base foi utilizada na identificação. 7. IMPORTAÇÃO DA BASE DE COLABORADORES POR EXCEL Crie um módulo administrativo chamado "Base de Colaboradores".
